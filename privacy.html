Muse Health — Privacy Policy

Effective date: November 7, 2026

What this application is

Muse Health is a personal-use tool operated by an individual (the "owner"). It consists of a command-line program that runs on the owner's own computer and reads the owner's Google Health data through the official Google Health API.

Data accessed

With the owner's consent, the application accesses the following Google Health data, read-only: activity and fitness data (such as steps and exercise), health metrics and measurements (such as weight and heart rate), sleep data, and basic profile information.

How the data is used

The data is used solely for the owner's personal health tracking and journaling, on the owner's own computer. It is not used for advertising, and it is not used to build profiles of any other person.

Storage

The application has no server of its own and sends no health data to the developer or to any third party. OAuth tokens are stored only in a configuration directory on the owner's own computer. Health data retrieved through the API is processed locally on that computer.

Sharing

Health data accessed through the Google Health API is never sold and never shared with third parties.

Limited Use

Muse Health's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deletion

The owner can revoke the application's access at any time from the Google Account permissions page (myaccount.google.com → Security → Third-party access). Deleting the locally stored token files on the owner's computer removes the application's ability to access the data.
