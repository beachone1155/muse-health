Muse Health

Muse Health is a personal-use tool operated by an individual for their own health tracking. It reads the owner's own Google Health data — such as steps, sleep, heart rate, and weight — through the official Google Health API, using a small command-line program (ghealth) that runs on the owner's own computer.

The data is used only for the owner's personal health journaling and daily review. The tool has no sign-up, no other users, and no server of its own: requests go directly from the owner's computer to Google's API.

This page exists as the application homepage for the OAuth consent screen of that tool.
